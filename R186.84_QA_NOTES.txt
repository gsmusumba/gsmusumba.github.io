GS MUSUMBA R186.84 — TEACHER PORTAL UI/ROUTING CORRECTION

ROOT CAUSES CONFIRMED FROM R186.83 SOURCE + USER SCREENSHOTS
1. Historical R186.81 teacher dashboard renderer intercepted dashboard before the new R186.83 GSM_VIEWS.dashboard could run. Result: old 6-card dashboard, R186.81 badge, old shortcuts, extra RPC calls, and dead old menu IDs.
2. teacher-portal.css deliberately hid #sidebar, footer and mobile navigation whenever a teacher service opened. Result: My Classes / Identification / other services lost the normal menu/sidebar.
3. New KPI cards used generic classes .green/.red/.gold. r18679-critical.css has generic !important color rules, causing contrast collisions. User saw pale/colored cards with unreadable text.
4. My Classes roster used percentage widths (especially SDMS 18% and STUDENT NAME remainder), producing poor column proportions on wide screens.
5. R186.83 KPI cards were display-only; they did not navigate when clicked.

R186.84 CORRECTIONS
- TEACHER dashboard now bypasses only the historical R186.81 dashboard interceptor; other roles retain their current dashboard authority.
- Before the lean teacher module loads, core does NOT start the old teacher dashboard RPC chain. This removes obsolete calls/flicker and improves login-to-dashboard path.
- Desktop sidebar/topbar remain visible on Dashboard and every Teacher service. Mobile keeps the existing off-canvas sidebar/burger behavior.
- Colored KPI and action surfaces use strong background authority and WHITE text for BLUE/GREEN/YELLOW(GOLD)/PURPLE/RED/NAVY/BLACK.
- White/light surfaces use dark navy text.
- Teacher dashboard has 4 compact equal clickable cards.
- Student Identification summary cards are clickable filters.
- My Classes roster, Student Identification and Attendance tables use controlled fit-to-content widths. Marks keeps a fixed formula-aware 11-column layout.
- PROFILE buttons use visible blue action styling.
- Service buttons retain working/busy/success/error feedback paths.
- Supabase/RPC formulas and live timetable data were NOT changed in this release.

REGRESSION SAFETY
- Other roles: no menu/dashboard behavior intentionally changed.
- Teacher data permissions: unchanged; backend remains source of truth.
- Marks formulas: unchanged, server-calculated.
- Attendance save logic: unchanged.
- Timetable source: unchanged, live Supabase.
