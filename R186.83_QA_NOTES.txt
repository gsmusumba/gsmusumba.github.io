IDENTIFICATION
- 4 equal compact cards: Total, Complete, Incomplete, Not Started.
- Search, Class, Missing Data, Sort, status tabs.
- Existing student data pre-fills Edit Profile.
- SDMS, Full Name, Sex, Current Class are locked in this workflow.
- Teacher can edit only class-teacher student profiles; subject-teacher students remain view-only.
- Save automatically submits for verification when the 10 required completeness fields are present.
- Save & Next Incomplete opens the next editable incomplete profile.

FORMULA SAFETY
- Marks UI does NOT calculate CAMIS, exam contribution, final percentage, grade, or rank.
- These values are displayed from r174_teacher_marks_entry_data (server formula authority).
- r174_teacher_save_marks / save_teacher_marks retain validation for max marks and mark-status rules.

COLOR AUTHORITY
- Red / Yellow(Gold) / Purple / Black / Navy / Blue / Green background => white text.
- White / light background => dark navy text.

MOBILE

- Forms use responsive 2-column then 1-column layouts.
