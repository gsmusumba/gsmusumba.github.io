GS MUSUMBA R186.85 — TEACHER PORTAL DEEP AUDIT / BUG / CALL / LOADING CORRECTION

PRIMARY CORRECTIONS
- Teacher authenticated shell loads the lean Teacher CSS/JS before first dashboard paint, preventing old-dashboard flicker and menu/sidebar races.
- Teacher no longer loads the large legacy r18661-app.css / r18661-extensions.js bundles. Other roles remain on the existing legacy workspace.
- Asset loader has timeout + one retry and fail-visible errors instead of endless loading.
- Duplicate concurrent read RPCs are deduplicated inside the Teacher portal; write calls are never deduplicated.
- Dashboard first paint uses bootstrap/cache immediately; secondary metrics load after the page is usable.
- Sidebar/topbar stay visible across Teacher services; old service-focus classes cannot remove navigation.
- Strong BLUE/GREEN/YELLOW(GOLD)/PURPLE/RED/NAVY/BLACK surfaces enforce WHITE text; light surfaces retain dark text.
- Teacher dashboard keeps 4 compact equal cards and clickable actions.
- Students Identification uses R186.85 class-teacher-scoped directory and a combined profile save RPC.
- Class Attendance selector now reuses the fast bootstrap and exposes ONLY class-teacher classes, removing the extra r161 scope call and eliminating dead class-attendance routes from subject-only classes.
- My Classes shows Identification/Class Attendance actions only where the teacher is the class teacher. Subject-only rosters are view-only for profile editing.
- Class Attendance and Subject Attendance Save use the save RPC response directly; no redundant reload call after save.
- Marks browser remains display/entry only. CAMIS / Exam / Total / Final % / Grade / Rank are returned by the server formula engine and are not recalculated in JavaScript.
- My Club and Lesson Plans are present in the lean Teacher menu.
- Service operations provide busy/success/error feedback; global unhandled errors are surfaced instead of failing silently.
- Service worker uses a new R186.85 cache and does not cache Supabase/API requests.
