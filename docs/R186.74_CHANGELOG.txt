GS MUSUMBA SCHOOL MANAGEMENT SYSTEM — R186.74 DISTRICT DASHBOARD POLISH FINAL

PURPOSE
Competition/district-facing dashboard and Teacher navigation polish built on R186.73 without replacing existing Supabase/RLS/write/print authority.

IMPLEMENTED
1. TEACHER MENU
   - Dashboard
   - My Timetable
   - Student Identification
   - My Students
   - Attendance
   - Marks & Assessments
   - Student Performance
   - My Club
   - Lesson Plans
   - Account
   - No standalone Reports menu. Reports stay inside the owning service.
   - Hidden compatibility routes preserve old internal Class Attendance, Subject Attendance, Absentee and Marks links without duplicating the visible menu.

2. TEACHER ATTENDANCE HUB
   - One visible Attendance menu.
   - Three equal desktop cards on the same row:
     CLASS ATTENDANCE | SUBJECT ATTENDANCE | ABSENTEES / FOLLOW-UP
   - Cards stack on small phones.

3. TEACHER DASHBOARD
   - Compact KPIs: Today's Lessons, My Students, Attendance Pending, Marks Pending, Absentees Today, Performance.
   - Today timetable preview.
   - Authorized-class Boys/Girls compact histogram.
   - Student Performance: subject selector / All My Subjects, Top 5 or Need Support 5, Primary and Secondary.
   - Performance is on-demand to avoid heavy mark queries during initial 2G dashboard opening.
   - Student roster and absentee preview are deferred after first usable paint; deferred further on Save-Data/2G.
   - Quick actions include Timetable, Student Identification, Attendance, Marks, Performance and Lesson Plans.

4. SUPER ADMIN DASHBOARD
   - Executive KPIs: Students, Boys, Girls, Attendance Today, Absent Today, Teachers.
   - Removed Live Services as a dashboard KPI.
   - All active classes Boys/Girls histogram with Chart/Table toggle.
   - Daily attendance summary by Nursery, Primary, Secondary and Whole School.
   - Compact absentee-by-class preview and only current action/attention items.
   - On-demand Primary/Secondary Top 5 or Need Support 5 performance.

5. DOS DASHBOARD
   - Same visual family as Super Admin with academic focus.
   - Class Boys/Girls histogram, daily attendance, performance and academic readiness.
   - Reports remain inside individual academic services.

6. DESIGN / COLOR
   - Segoe UI / Arial operational font authority.
   - Navy/dark blue headings, blue data/navigation, green success, gold/amber warning, strong red #c93434 only for critical/not-called states.
   - Compact cards, headings and tables.
   - Dashboard layouts use minmax(0,1fr) grids to prevent unnecessary laptop horizontal scrolling.
   - Actual NO. columns remain approximately 38 px / 1 cm where used.

7. PERFORMANCE SAFETY
   - Existing R186.73 authenticated shell, parallel heavy CSS/JS loading and service worker retained.
   - R186.74 cache/version keys added so old R186.73 assets cannot mask the new release.
   - No Supabase/Auth/API response is added to the service-worker cache.

NOT CHANGED
- Supabase database schema, RLS, formulas, marks write authority, attendance write authority, timetable write authority, report-card formulas and centralized printing authority are preserved.
- No claim of guaranteed cold-load under 1 second on every real 2G network. Live district testing must measure actual network and Supabase latency.
