AUDIT MEANING:
- Every known same-window print path is normalized by the final R186.71 beforeprint stage.
- Every popup print opened through window.open is wrapped by R186.71 popup normalization.
- The final layer is appended after inherited print layers, so legacy headers cannot become the final printed header.
- Static/runtime-route audit is system-wide; it is not a claim that all 135 services were manually clicked one-by-one in a browser.
- Manual browser QA is still required on representative high-risk families before production push.

GLOBAL PRINT STANDARD:
- ONE official School Profile; bold, vertical, left aligned.
- Academic Year, Term, Date on the left.
- Document title once.
- No application/system name inside printed document body/header/footer.
- Prepared By / Verified By / Approved By on official outputs.
- Timetable: A4 landscape, one-page default.
- Long marks/attendance registers: readable multipage output; table headers repeat where browser supports thead printing.
- Print Settings: paper size, orientation, fit/scale, margins, colour/B&W, editable header title, report date, footer text.
- Chrome/Edge browser Headers and footers must be OFF to suppress browser URL/date/page chrome.
